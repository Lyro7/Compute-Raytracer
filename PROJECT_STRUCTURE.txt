=========================
RAYTRACER PROJECT STRUCTURE
=========================

# Root
CMakeLists.txt          -> Projekt-Konfiguration
CMakePresets.json       -> Build-Presets
README.md               -> Benutzerbeschreibung
PROJECT_STRUCTURE.txt   -> Diese Übersicht (nur für Entwickler)
.gitignore              -> ignorierte Dateien (out/, build/, .o, usw.)

──────────────────────
assets/                 -> Laufzeitdaten (nicht kompilieren)
│  ├─ models/           -> .obj / .mtl Dateien
│  ├─ textures/         -> .png / .jpg / .hdr
│  └─ scenes/           -> Szenenbeschreibungen (.json, .yaml)
│
shaders/                -> GLSL Shader
│  ├─ screen.vert
│  └─ screen.frag
│
external/               -> Third-Party Libraries
│  ├─ glad/             -> OpenGL Loader
│  ├─ glfw/             -> Windowing/Input
│  ├─ glm/              -> Math Library (header-only)
│  └─ tiny_obj_loader.h -> OBJ Loader Header
│
include/                -> Öffentliche Header (Interfaces)
│  ├─ mesh.h
│  └─ loader.h
│
src/                    -> Eigener Projektcode
│  ├─ app/              -> main.cpp, Programmstart
│  ├─ io/               -> Datei-Import/-Export, Loader
│  ├─ scene/            -> Objekte, Kamera, Materialien
│  ├─ core/             -> Raytracing-Kern, Mathematik berechnungen 
│  ├─ gfx/              -> OpenGL-/GPU-Hilfen
│  ├─ ui/               -> Benutzeroberfläche (Qt oder ImGui)
│  └─ utils/            -> Helferklassen (Logger, Timer, Parser)
│
out/                    -> Build-Ausgabe (gitignored)
──────────────────────

# Notes
- 'external/' enthält keine eigenen Dateien, nur eingebundene Libraries.
- 'include/' bleibt öffentlich; Implementierungen in 'src/'.
- 'assets/' & 'shaders/' werden zur Laufzeit kopiert, nicht kompiliert.
- 'out/' wird automatisch beim Build erstellt.
